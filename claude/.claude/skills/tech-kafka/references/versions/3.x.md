# Kafka 3.x deltas (3.3 to 3.9)

Only the first 100000 characters of the source page were read. ZooKeeper migration status and ZooKeeper deprecation timeline were NOT stated in what was read, so they are left out. Verify before relying on them.

Overrides `references/core/` where they conflict. Compare with `4.x.md` when planning an upgrade.

## Mode

- ZooKeeper and KRaft both exist on 3.x. `zookeeper.connect` means ZooKeeper mode, `process.roles` means KRaft.
- 3.3.1: KRaft production ready for new clusters (KIP-833). KRaft upgrades follow a different process than ZooKeeper upgrades.
- KRaft upgrade: bump `metadata.version` with `kafka-features.sh upgrade --metadata <x.y>`. Metadata downgrade is not supported after metadata changes.
- 3.9 is the last 3.x release. 4.x requires KRaft brokers on at least 3.3.x, so ZooKeeper clusters must migrate to KRaft before moving to 4.x.

## Changes by minor

- 3.3: default partitioner for keyless records changed (KIP-794).
- 3.4: `JndiLoginModule` disabled by default.
- 3.5: MirrorMaker uses `incrementalAlterConfigs` by default (KIP-894), `use.incremental.alter.configs` deprecated. Versioned key-value state stores (KIP-889).
- 3.6: transaction partition verification (KIP-890) enabled by default. Tiered storage early access, not for production.
- 3.7: KIP-848 consumer protocol early access, not for production. Java 11 for broker and tools deprecated, removal in 4.0. Client APIs from before 2.1 deprecated, removal in 4.0 (KIP-896).
- 3.8: JBOD in KRaft no longer early access. Tiered storage still early access, supports multiple log directories.
- 3.9: tiered storage production ready. `unclean.leader.election.enable` supported in KRaft. KRaft controller membership change supported when formatting with `--standalone` or `--initial-controllers`.

## Preparing for 4.x

- Move off ZooKeeper to KRaft first.
- Check every client is on 2.1 or higher.
- Remove use of configs removed in 4.0 (see `4.x.md`).
- Plan for Java 17 on brokers and Connect, Java 11 for clients.
- Expect `linger.ms` default to change from 0 to 5 at 4.0.

## Not verified

- ZooKeeper to KRaft migration maturity per minor version.
- Minimum Java version per 3.x minor.
